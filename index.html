Detailed Curriculum

12 modules, practical labs, and mini projects.

Each module combines concept learning, live lab work, AI integration, and GitHub-based deliverables.

Module 0

DevOps Foundation Bridge

+
DevOps lifecycle, Linux essentials, GitHub workflow, YAML basics, and AI's role in DevOps.
  • Set up local DevOps workspace
  • Create GitHub repository
  • Write first automation script
Module 1

Linux, Bash & Python Automation

+
Automate system checks, logs, APIs, cron jobs, and reports.
  • Health-check scripts
  • Log cleanup automation
  • CPU, memory, and disk reporting
Module 2

GitHub, CI/CD & Intelligent Pipelines

+
Build CI/CD pipelines with testing, scanning, Docker build, deployment, and AI failure summaries.
  • GitHub Actions
  • Pipeline debugging
  • AI-assisted failure reports
Module 3

Docker & Container Intelligence

+
Containerize apps, write Dockerfiles, use Compose, inspect logs, and review container security.
  • Flask/FastAPI containerization
  • Docker Compose stack
  • AI Dockerfile optimization
Module 4

Kubernetes for AI-Powered DevOps

+
Deploy workloads with Minikube or Kind, use Helm, debug events, and build a Kubernetes troubleshooting assistant.
  • Pods and deployments
  • Services and ingress
  • AI log/event explanations
Module 5

IaC with OpenTofu/Terraform & Ansible

+
Provision infrastructure, manage state, configure servers, and detect misconfigurations.
  • OpenTofu/Terraform basics
  • Ansible playbooks
  • AI-assisted IaC review
Module 6

Observability Fundamentals

+
Metrics, logs, traces, SLI/SLO/SLA, RED/USE, Prometheus, Grafana, OpenTelemetry, and alerts.
  • Dashboards
  • Alerting
  • Telemetry collection
Module 7

AIOps: Logs, Anomaly Detection & RCA

+
Parse logs, detect error spikes, build anomaly detection models, and generate incident summaries.
  • Python log parser
  • Scikit-learn anomaly model
  • Incident report generator
Module 8

AI-Assisted Incident Response & SRE

+
Build runbooks, triage alerts, draft postmortems, and design AI-assisted incident workflows.
  • Severity classification
  • Root-cause suggestions
  • Runbook recommendation
Module 9

Secure AI in DevOps

+
Prevent secret leakage, prompt injection, unsafe commands, and insecure generated scripts.
  • Gitleaks and Trivy
  • Human approval gates
  • DevSecOps basics
Module 10

MLOps & AI Model Deployment

+
Train, package, containerize, deploy, monitor, and version ML models using DevOps principles.
  • MLflow tracking
  • Model API deployment
  • Model monitoring
Module 11

Building a DevOps AI Assistant

+
Create a documentation-aware DevOps assistant with RAG, log summarization, guardrails, and response evaluation.
  • Runbook search
  • Tool-use concept
  • Safety warning layer
